Sistem Pemesanan Layanan TeFa - SMKN 1 Katapang

Aplikasi Web Sistem Pemesanan Layanan berbasis Laravel yang dibangun untuk memenuhi kriteria Seleksi Produksi Teaching Factory (TeFa) RPL.

Tech Stack
- Framework: Laravel 11
- Database: MySQL (XAMPP)
- Frontend: Blade & Tailwind CSS

Fitur Utama
1. Management Data Layanan (CRUD)
2. Management Data Pelanggan (CRUD)
3. Transaksi Pemesanan (Relasi Multi-Tabel)
4. Update Status Pemesanan (Pending / Selesai)
5. Filter & Pencarian Data
6. Ringkasan Dashboard Ringkas
